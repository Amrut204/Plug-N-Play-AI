1. PLATFORM OVERVIEW & ARCHITECTURAL PHILOSOPHY
================================================================================
Plug-N-Play AI is an enterprise-grade, zero-write AI data layer and autonomous agent orchestration platform. It enables businesses, developers, and organizations to connect their private databases, unstructured documents, and web services to AI agents and embed intelligent assistants directly into any website or web application within minutes.

Key Value Proposition:
- "Bring AI to your data, never your data to an external black box."
- Dual-Engine Architecture: Unlike single-purpose chatbots that only do document search, Plug-N-Play AI seamlessly unifies two distinct retrieval engines:
  1. Unstructured Document Retrieval (RAG via Vector Embeddings)
  2. Structured Operational Database Querying (Text-to-SQL with AST Safety)
- Multi-Tenant Isolation: Every workspace is strictly sandboxed. Workspaces cannot access or query data, vector embeddings, or chat histories belonging to any other tenant.
- Zero Database Write Access: The platform operates under a non-negotiable read-only mandate. Destructive SQL operations (DROP, DELETE, UPDATE, INSERT, ALTER) are blocked at the abstract syntax tree (AST) level before reaching any database.

2. CORE AGENT TYPES & CAPABILITIES
================================================================================
Plug-N-Play AI supports three distinct agent modes that can be combined or configured independently:

A. KNOWLEDGE BASE (UNSTRUCTURED RAG AGENTS)
- Purpose: Answers customer inquiries, support questions, policy lookups, and handbook references from uploaded documents.
- Supported Ingestion Formats: PDF (.pdf), Plain Text (.txt), Markdown (.md), CSV (.csv), JSON (.json), and DOCX (.docx).
- Ingestion Pipeline:
  1. Document Parsing: Extracts text and tabular content while stripping formatting artifacts.
  2. Semantic Chunking: Splits content into overlapping semantic windows (default 500 characters with 100 character overlap) to preserve conversational context across chunk boundaries.
  3. Vector Embedding: Generates dense vector representations using state-of-the-art embedding models.
  4. Hybrid Retrieval: Queries are compared against vector indexes using cosine similarity; top-k relevant snippets are injected dynamically into the LLM system prompt.

B. DATABASE QUERYING (OPERATIONAL TEXT-TO-SQL AGENTS)
- Purpose: Answers natural-language questions about live structured operational data (e.g., "What is the status of order #9821?", "How many students have attendance above 85%?").
- Supported Engines: SQLite, PostgreSQL, MySQL.
- Security & AST Validation Engine:
  - Every SQL query generated by the LLM is inspected by an Abstract Syntax Tree (AST) validator before execution.
  - Queries must strictly be pure `SELECT` statements.
  - Semicolon chaining (multiple queries), comments, file execution (`INTO OUTFILE`), and schema tampering (`DROP`, `ALTER`, `TRUNCATE`, `UPDATE`, `INSERT`) are instantly intercepted and rejected with security violations logged.
  - Self-Healing Query Retries: If a SQL query fails due to a syntax error or non-existent column, the platform captures the error, reflects the schema back to the LLM, and retries automatically up to 3 times.

C. ACTION AGENTS & AMBIENT BROWSER RELAYS
- Purpose: Enables agents to trigger real-world business actions on behalf of the user directly within their browser session.
- Capabilities:
  - External API Callouts: Dispatch authenticated HTTP POST/GET requests to client backends and webhooks.
  - Ambient Browser Relays: Uses the visitor's existing session cookies and CSRF tokens to execute actions inside the web page (such as adding items to cart, opening a specific tab, or submitting a feedback form) without exposing backend administrative API keys.

4. WEB APPLICATION INTEGRATION & EMBEDDING GUIDE
================================================================================
Integrating an agent into any website requires only a single script snippet generated in the Agent Studio.

A. EMBED SCRIPT SNIPPET FORMAT
```html
<script 
  src="https://plug-n-play-rag.onrender.com/static/widget.js" 
  data-agent-id="YOUR_AGENT_ID_HERE"
  async>
</script>
```

B. FRAMEWORK-SPECIFIC IMPLEMENTATIONS:
1. Static HTML & WordPress:
   - Paste the `<script>` tag inside `index.html` just before the closing `</body>` tag, or in your WordPress theme's `footer.php`.
2. React (TSX / JSX):
   - In your root `index.html` or inside a top-level component's `useEffect()`:
   ```typescript
   useEffect(() => {
     const script = document.createElement('script');
     script.src = "https://plug-n-play-rag.onrender.com/static/widget.js";
     script.setAttribute('data-agent-id', 'YOUR_AGENT_ID');
     script.async = true;
     document.body.appendChild(script);
     return () => { document.body.removeChild(script); };
   }, []);
   ```
3. Next.js (App Router / Pages Router):
   - Use Next.js `<Script>`:
   ```tsx
   import Script from 'next/script';
   <Script 
     src="https://plug-n-play-rag.onrender.com/static/widget.js" 
     data-agent-id="YOUR_AGENT_ID" 
     strategy="afterInteractive" 
   />
   ```
4. Angular:
   - Add the script URL to `angular.json` under `"scripts": []`, or inject dynamically in `app.component.ts`.
5. Vue 3 & Nuxt 3:
   - In `App.vue` inside `onMounted()`, or in `nuxt.config.ts` under `app.head.script`.
6. Backend Server Bridges (Python, Node.js, PHP/Laravel):
   - Query agents programmatically via REST API:
     `POST /api/v1/chat/query` with headers `{"X-API-Key": "YOUR_MASTER_KEY"}` and JSON `{"agent_id": "...", "query": "..."}`.

5. SECURITY, COMPLIANCE & TENANT ISOLATION
================================================================================
1. Zero Database Write Guarantee:
   - The platform never requests administrative or write database credentials.
   - All queries run under strict read-only execution modes with AST validation.
2. Data Privacy:
   - Uploaded documents and vector embeddings are segregated by Tenant ID.
   - Query data is never used to train foundational public LLMs.
3. Authentication & Credential Safeguards:
   - Google OAuth (GIS) token verification performed securely server-to-server over HTTPS (Port 443).
   - Passwords hashed using industry-standard salted Argon2/Bcrypt.
   - Master API keys are cryptographically generated with SHA-256 validation.

6. HUMAN ESCALATION & LIVE SUPPORT HANDOVER
================================================================================
When a customer conversation requires human intervention:
- Trigger: A user explicitly asks to speak with a human, or the agent detects severe frustration / policy ambiguity.
- Escalation Flow:
  1. The agent asks the visitor for their preferred contact info (email or phone).
  2. The system triggers `EmailService.send_escalation_email`.
  3. A rich, branded HTML escalation dispatch is routed to the workspace's configured support email via secure HTTPS APIs (Resend/Brevo/SendGrid).
  4. The dispatch contains the visitor contact, latest query, conversation transcript, and a direct link to the Master Studio session.

7. FREQUENTLY ASKED QUESTIONS (FAQ) FOR PLATFORM ASSISTANT
================================================================================
Q: What is Plug-N-Play AI?
A: Plug-N-Play AI is an enterprise AI platform that connects private databases (Text-to-SQL) and documents (RAG) to embeddable AI agents for any website or app in minutes.

Q: Can the agent modify or delete records in my database?
A: Absolutely not. Plug-N-Play AI enforces a strict Zero Database Write policy. Our AST SQL Validator rejects any INSERT, UPDATE, DELETE, DROP, or schema-altering query before execution.

Q: What document types can I upload to train my agent?
A: You can upload PDF (.pdf), plain text (.txt), Markdown (.md), CSV (.csv), JSON (.json), and Microsoft Word (.docx) files.

Q: How do I embed the agent on my website?
A: Go to the Agent Studio, select your agent, and copy the embed code snippet. Paste the `<script>` tag before the `</body>` tag on your website (compatible with WordPress, React, Next.js, Angular, Vue, and plain HTML).

Q: How do I sign in or create an account?
A: You can use 1-Click Google Sign-In with your Google account, or register with your email and password. Email verification codes are delivered over secure HTTPS.

Q: Can I log out or update my profile?
A: Yes. Click your profile avatar in the top right to view your account details in read-only mode. Click "Edit Profile" to change your name or company, or click the "Logout" button in the navigation header to sign out.

Q: Which LLM models power Plug-N-Play AI?
A: The platform utilizes ultra-fast inference engines powered by Groq, supporting LLaMA 3.3 70B, Qwen 2.5 32B, DeepSeek R1 distillation, and OpenAI-compatible endpoints with automatic failover.
