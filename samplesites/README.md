# Plug-N-Play AI — Multi-Framework Sample Websites

This directory contains **10 standalone, production-ready sample websites** across different frontend frameworks and backend bridges so you can test and verify Plug-N-Play AI code snippets in realistic environments.

---

## 📁 Directory Structure & Quick Start

| # | Framework / Target | Path | How to Run |
|---|---|---|---|
| **1** | **HTML / WordPress / Webflow** | `1-html-wordpress/` | Simply open `index.html` in any web browser |
| **2** | **React (TypeScript / TSX)** | `2-react-tsx/` | `npm install` ➔ `npm run dev` |
| **3** | **React (JavaScript / JSX)** | `3-react-jsx/` | `npm install` ➔ `npm run dev` |
| **4** | **Next.js (App Router)** | `4-nextjs-app-router/` | `npm install` ➔ `npm run dev` |
| **5** | **Angular (TS Component)** | `5-angular-ts/` | `npm install` ➔ `npm start` |
| **6** | **Vue 3 / Nuxt 3** | `6-vue3-nuxt3/` | `npm install` ➔ `npm run dev` |
| **7** | **Svelte / SvelteKit** | `7-svelte-kit/` | `npm install` ➔ `npm run dev` |
| **8** | **Node.js Bridge (Zero-Knowledge)** | `8-nodejs-bridge/` | `npm install` ➔ `npm start` (Runs on `http://localhost:3000`) |
| **9** | **Python Bridge (FastAPI)** | `9-python-bridge/` | `pip install -r requirements.txt` ➔ `python main.py` (Runs on `http://localhost:5000`) |
| **10** | **PHP Bridge (Laravel)** | `10-php-laravel-bridge/` | `composer install` ➔ `php artisan serve` |

---

## 🧪 Testing Instructions

1. Start your Plug-N-Play AI backend server (`http://127.0.0.1:8000`).
2. Build an agent in the **Agent Studio** or use the default agent.
3. Open **Step 4 (Customize & Deploy)** in the studio.
4. Copy the snippet for your desired framework and paste it into the designated component file in the corresponding folder above.
5. Launch the sample website and verify the floating AI widget or bridge API in action!
